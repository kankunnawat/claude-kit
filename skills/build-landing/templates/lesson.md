# Lesson: <slug>

## What broke
One paragraph. The symptom as the owner or the reader saw it.

## What fixed it
The change, in one paragraph. Name the file and commit.

## Proposed rule
One line. Where it lands: a checklist row, a script check, or the project context.

## Evidence path
A commit, a file and line, or an evidence directory.

## Ledger row
One ledger table row plus at most two note sentences: public address, unsigned response, hash parity, date. Omit the section when the site did not deploy.
